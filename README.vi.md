![WordPress](https://img.shields.io/badge/WordPress-21759B?style=flat-square&logo=wordpress&logoColor=white) ![WooCommerce](https://img.shields.io/badge/WooCommerce-873EFF?style=flat-square&logo=woo&logoColor=white) ![PHP](https://img.shields.io/badge/PHP-777BB4?style=flat-square&logo=php&logoColor=white) ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)

## Làm việc cùng AI

- Dùng Claude Code, Cursor và Codex hằng ngày cho theme Shopify: dựng section từ Figma, review code và QA.
- Viết rules cho dự án (`AGENTS.md`) và quy trình để agent làm theo đúng pattern có sẵn của theme.
- Dùng AI cho phân tích nghiệp vụ: soạn đặc tả và thiết kế hệ thống, như hệ thống đại lý ở trên.
- Tự xây thư viện skill cho agent, ví dụ skill review pull request theme Shopify.
- Dùng agent tự động hoá việc hành chính của team: chuyển kết quả nghiên cứu thành task, chụp ảnh bằng chứng và đưa task vào công cụ quản lý task nội bộ.
- Nhờ quy trình này tôi làm một mình được các dự án WordPress và Laravel.
